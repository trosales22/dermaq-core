# DermaQ Core

DermaQ is a smart online portal designed for skincare clinics to streamline appointment scheduling and inventory tracking. 
Instead of customers rushing to the clinic early in the morning, admins create available booking sessions, 
allowing customers to register and secure a slot through the landing page. With real-time availability and a smooth management system, 
DermaQ ensures a hassle-free experience for both clients and clinic staff.

## Stack
- React (TypeScript)
- TailwindCSS
- DaisyUI
- Tanstack Query
- React Hook Form + Zod
- Cloudinary

## Setup
- Run `npm install`
- Adjust the ff. in .env
```bash
  VITE_WS_BASE_URL=
  VITE_CLOUDINARY_CLOUD_NAME=
  VITE_CLOUDINARY_UPLOAD_PRESET=
  VITE_SITE_URL=
```
- Execute the ff. to run:
```bash
npm run dev
```
